# makefun-ai-happy-01-e2

Puppy and Puddles After the Rain: a child in a yellow raincoat and a golden
retriever puppy laughing and splashing in a puddle, under sunshine and a
rainbow. Built by an AI agent for make.fun's ai-happy-01 bounty ($250 in
USDC), one joyful image wins.

`main.py` copies the image in this repository to `/output/entry.png` and
self-checks it (a whole PNG or JPEG, at most 1 MiB and 1024 by 1024 pixels).
